# Edit Guide

_Auto-generated by `gc build`. Read this first; then `INDEX.md` for the rest._

A GoatCheese project is **three layers**; the layer decides whether an edit survives:

1. **Generated** &mdash; emitted from `schema/*.hjson` on every `gc build`
   (`Built/` dirs, routes, menus, permissions). Overwritten **every build**.
2. **Template** &mdash; copied from `apigoat/template` at `gc create`, re-copied by
   `gc upgrade` / `gc build --sync-template` (a plain `gc build` only *reports* drift).
3. **Yours** &mdash; `*Wrapper.php`, `Domains/`, `schema/*.hjson`, `tests/Custom/`. Never overwritten.

Before writing custom code, check the `goatcheese-behaviors` skill
(`<project>/.claude/skills/`): most features are an existing HJSON behavior,
and re-implementing one inline is the #1 source of drift. The build/deploy
loop itself is documented in the `gc` skill next to it.

## Safe to edit (yours)

- `src/App/Domains/` &mdash; business logic
- `src/App/Services/*ServiceWrapper.php` &mdash; per-table service extensions (custom actions, response shaping)
- `src/App/Interfaces/*FormWrapper.php` &mdash; form hooks (`beforeSave`, `afterFormObj`, `afterSave`, validators)
- `src/App/Models/` (non-`Built/`) &mdash; model overrides
- `tests/Custom/` &mdash; your tests (**required** for any custom logic)
- `../schema/*.hjson` &mdash; the data model (project-root `schema/`; legacy `.admin/*.hjson` is migrated on the next build)
- `public/css/_variables.scss`, `public/css/project.scss`, `public/css/print.scss` &mdash; the only per-project style files
- `public/js/project.js` &mdash; the only per-project script file (loads last; see `REALTIME.md`)
- `src/App/Domains/RealtimeHandler.php` &mdash; optional realtime sidecar hooks (**read `REALTIME.md` first** &mdash; it runs in a long-lived event loop, not a request)
- `config/custom*.sql` &mdash; seeds replayed after build; first lines containing `gc:dev-only` = sample data (not deployed, not kept by `resetdata`)

## Do NOT edit (regenerated every build)

`.build/classes/`, `config/Built/`, `src/App/{Models,Services,Interfaces}/Built/`,
`tests/Builder/Generated/`, `vendor/`, `public/{css,js}/min/`, `schema.xml` / `*.schema.xml`.
To change a `Built/` class, edit the matching `*Wrapper.php` &mdash; it extends the built class.

## Template-managed (overwritten on `gc upgrade` / `--sync-template`)

- `public/js/*.js`, `public/js/app/*.js` &mdash; framework client (`gcUpload`, list, form widgets) &mdash; **except `public/js/project.js`, which is yours**
- `public/css/*.scss|css` except the three per-project files above
- `public/*.php`, `sw.js`, `manifest.webmanifest`, PWA icons, `public/view/notifications-settings.php`
- `config/assets.php`, `composer.json` &mdash; **union-merged**: your additions survive, template removals are dropped
- `tests/Builder/**` &mdash; framework tests
- `.claude/skills/gc/` &mdash; the gc skill

Report-only (drift shown, never overwritten): `src/App/Domains/Template/Variables.php`, `*FormWrapper.php` skeletons.
Seeded once at create, never synced: `public/view/account.php`, `AccountServiceWrapper.php`, the `Account` routes, `authy.theme`.
A fix that belongs in every project goes in the **template** repo, not here.

## Add a table

1. Add it to a `schema/*.hjson` file (behaviors first &mdash; see the skill).
2. `gc build` (from `.admin/`: `../gc build`).
3. Extend the new `*FormWrapper.php` / `*ServiceWrapper.php`; routes, menus, permissions are emitted to `config/Built/`.
4. Add tests under `tests/Custom/`; confirm in `SCHEMA-OVERVIEW.md` / `ENTITIES.md`.

## Custom logic

**Custom action** &mdash; register in the `*ServiceWrapper` constructor; both the HTML and JSON dispatchers use the same map:

```php
class ClientServiceWrapper extends ClientService {
    public function __construct($request, $response, $args) {
        parent::__construct($request, $response, $args);
        $this->customActions['exportCsv'] = 'exportClientsCsv';
    }
    public function exportClientsCsv($Api) {
        return ['status' => 'success', 'data' => [/* ... */]];
    }
}
```
→ `GET /Client/exportCsv` and `GET /api/v1/Client/exportCsv` (envelope in `API.md`).

**Form hooks** on `*FormWrapper.php`: `beforeSave($obj, $data)` (mutate or throw to veto),
`afterFormObj(array $data, $obj)` (`$obj` by reference; fires on every table &mdash;
no `add_hooks` opt-in needed), `afterSave($obj, $data)`. From `afterFormObj`, `$this->addFormTab(_('Email'), $safeHtml, ['first' => true])`
adds a custom drawer tab (needs `add_tab_columns` on the table; `first` makes it the tab open on load). Never set `id_creation`,
`id_group_creation`, `date_creation`, `date_modification` by hand &mdash; the framework
manages them and RBAC row-filtering depends on them.

## Testing

| Path | What | Editable |
|---|---|---|
| `tests/Builder/Generated/` | emitted shape tests (emitter regressions only) | no |
| `tests/Builder/Auth/`, `Smoke/` | framework tests | no (template) |
| `tests/Custom/` | **your** hooks, actions, domain logic, regression tests | **yes** |

DB tests extend `Tests\Builder\Auth\AuthyTestCase` (boots Propel, rolls back per test);
pure logic uses `PHPUnit\Framework\TestCase`. Run `vendor/bin/phpunit --testsuite custom|builder`.
Both suites green before a commit / after a build.
